# Commenter le code

1. Recense les fichiers sources et de tests dans le périmètre demandé. Par défaut, parcours tout le projet. Écarte les dépendances, les fichiers générés et les caches.  


2. Résume le rôle de chaque fichier. Explique ce que fait chaque classe, fonction et méthode et comment elle le fait, y compris les définitions privées, imbriquées et asynchrones. Vise une ou deux phrases par définition. Précise les entrées, les résultats, les erreurs et les effets de bord utiles à la compréhension.


3. Pour chaque test, résume le scénario, la préparation, l’action et ce que les assertions vérifient. Documente aussi les fixtures et les fonctions auxiliaires.  


4. Utilise les docstrings en Python et suis les conventions du projet dans les autres langages. Dans le corps du code, réserve les commentaires aux règles, calculs et cas limites qui demandent une explication. Complète les commentaires existants et préserve le comportement.  


5. Vérifie la couverture fichier par fichier, relis le diff et exécute les tests pertinents. Signale les éléments en suspens.
